# Nikhitha K — Semantic HTML5 Portfolio

A multi-page portfolio created for the HTML5 Semantic Structure & Accessibility assignment.

## Pages
- `index.html` — Home
- `about.html` — About
- `projects.html` — Projects
- `contact.html` — Accessible contact form

## Accessibility features
- Semantic HTML5 landmarks
- Skip-to-content link
- Keyboard-friendly navigation
- Visible focus states
- Proper form labels
- `aria-label`, `aria-current`, `aria-expanded`, `aria-live`, and `aria-invalid` where useful
- Responsive mobile navigation
- Reduced-motion preference support
- Descriptive page titles and meta descriptions

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Before submission
1. Replace `your-email@example.com` in `contact.html` with your actual email.
2. Add real project links/screenshots if required.
3. Run Chrome DevTools → Lighthouse → Accessibility + SEO.
4. Test keyboard navigation using Tab and Shift+Tab.
5. Test at mobile width.
