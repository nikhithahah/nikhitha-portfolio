# Advanced CSS3 & Responsive Portfolio

## Files
- `index.html` — semantic portfolio structure
- `style.css` — advanced CSS3, Grid, Flexbox, variables, dark mode and responsive media queries
- `script.js` — mobile menu and persistent light/dark theme toggle

## How to run
1. Keep all three files in the same folder.
2. Open `index.html` in a browser.
3. Replace the placeholder name, email, GitHub and LinkedIn links with your own details.

## Assignment requirements covered
- CSS Grid for two-dimensional layouts
- Flexbox for navigation, buttons, tags and component alignment
- Mobile-first responsive architecture
- Responsive breakpoints for tablet and desktop
- CSS custom properties / variables
- Light and dark mode
- Semantic HTML
- Hover and focus-friendly interactions
- Responsive navigation menu
- Accessible labels and reduced-motion support
